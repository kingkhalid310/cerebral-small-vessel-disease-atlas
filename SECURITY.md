# Security and sensitive-data policy

This is a static educational repository and should contain no secrets or protected data.

Do not open a public issue containing credentials, unpublished patient-level data, protected health information, accession numbers, medical-record numbers, dates of birth, or clinical images. If sensitive information is discovered, do not quote it in a public report. Contact the repository owner privately and identify only the affected path and commit.

The repository intentionally uses no runtime database, authentication system, analytics tracker, or server-side form.
