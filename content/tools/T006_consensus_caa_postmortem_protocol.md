# T006: Consensus CAA postmortem protocol

- **Category:** pathology protocol
- **Intended context:** Standardize sampling and severity assessment
- **Target construct:** Vascular amyloid distribution and severity
- **Required inputs:** Specified brain regions and amyloid stains
- **Output:** Region- and vessel-based CAA assessment

## Evidence and use

- **Development/authority:** International consensus pathology group
- **Validation status:** Consensus/appraisal protocol
- **Reference standard:** Histopathology itself
- **Key strength:** Improves comparability of tissue studies
- **Failure mode:** Sampling still misses patchy lesions; interlaboratory variation
- **Clinical status:** Research/neuropathology
- **Version/access:** 2014 protocol
- **References:** R026
- **Reviewed:** 2026-08-18
