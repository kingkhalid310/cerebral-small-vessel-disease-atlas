# T007: VCING

- **Category:** neuropathology framework
- **Intended context:** Estimate likelihood that vascular pathology contributed to cognitive impairment
- **Target construct:** Vascular contribution to cognitive impairment
- **Required inputs:** Standardized neuropathology including infarcts and vessel disease
- **Output:** Low/intermediate/high likelihood contribution

## Evidence and use

- **Development/authority:** Consensus with cohort validation
- **Validation status:** Validated for contribution framework
- **Reference standard:** Clinical-pathologic association
- **Key strength:** Forces integration of lesion burden and cognition
- **Failure mode:** Not an antemortem etiologic diagnosis; incomplete for all mixed pathologies
- **Clinical status:** Research/neuropathology
- **Version/access:** 2016 guidelines
- **References:** R025
- **Reviewed:** 2026-08-18
