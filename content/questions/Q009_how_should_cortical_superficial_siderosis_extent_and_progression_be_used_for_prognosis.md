# Q009: How should cortical superficial siderosis extent and progression be used for prognosis?

- **Domain:** CAA prognosis
- **Priority:** high
- **Evidence status:** bounded
- **Last searched:** 2026-08-18

## Review frame

- **Population:** Probable or pathology-confirmed CAA
- **Index/exposure:** Focal/disseminated cSS and interval change
- **Comparator:** No cSS or static rating
- **Reference standard:** Recurrent hemorrhage and functional outcomes
- **Outcome:** Absolute risk and incremental value

## Current synthesis

cSS is associated with recurrence risk, but treatment decisions require absolute and context-specific risk.

## Missing piece

Calibrated external models and treatment interaction evidence.

## Decisive design

Prospective competing-risk cohort with prespecified cSS progression
