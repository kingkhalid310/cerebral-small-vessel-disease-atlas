# Roadmap

## v0.4 — Repository foundation

- Searchable public interface backed by structured evidence.
- Clear public, clinical, and editorial boundaries.
- Manual evidence intake with automated structural validation.
- GitHub Pages and custom-subdomain readiness.

## v0.5 — Editorial strengthening

- Independent second-reviewer checks for high-impact claims.
- A formal correction log and claim-change history.
- Stable public identifiers and release archives.
- Improved source-level appraisal completeness.
- A deliberate content/code licensing decision.

## v0.6 — Evidence depth

- Broader pathology-standardization evidence.
- Stronger arteriolosclerosis MRI-autopsy mapping.
- Expanded mixed-pathology and transportability analyses.
- Cross-question synthesis pages and visual evidence neighborhoods.

## Future website release

- Activate GitHub Pages from `/docs`.
- Add `csvd.medics-global.com` only after content and license review.
- Preserve the zero-tracker, no-login, no-patient-data architecture unless a later need justifies a different boundary.

The roadmap does not include automated literature updates. Editorial control remains human.
