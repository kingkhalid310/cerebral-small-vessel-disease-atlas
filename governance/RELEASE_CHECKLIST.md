# Release checklist

Use this gate before publishing a new tagged release.

## Scientific integrity

- [ ] Every claim has at least one evidence relationship and a decisive next test.
- [ ] Supporting, qualifying, challenging, contextual, and methodological evidence are not collapsed.
- [ ] Diagnostic accuracy is reported with population, presentation, reference standard, and threshold.
- [ ] Derivation, internal validation, external validation, reproducibility, and outcome association are labeled separately.
- [ ] Citation-only and abstract-only records are not presented as full-text appraisals.
- [ ] Provisional single-reviewer judgments remain visibly labeled.
- [ ] Important negative, null, and transportability evidence has been sought.

## Reproducibility and provenance

- [ ] Search logs include source, query, date, coverage, and limitations.
- [ ] Screening decisions match the source registry.
- [ ] Study, claim, tool, and evidence-edge identifiers resolve without orphans.
- [ ] Bibliographic fields distinguish verified metadata from fields not yet extracted.
- [ ] The release date and change log are current.
- [ ] The validator passes without suppressed failures.

## Publication boundary

- [ ] No protected identifiers, patient-level data, unpublished cohort output, or credential material is present.
- [ ] Supplied PDFs are not redistributed without permission.
- [ ] Report-derived findings are labeled as candidate phenotype evidence, not validated criteria.
- [ ] Clinical criteria and tools are described as educational unless current clinical authority supports use.

## Document quality

- [ ] The generated Word edition matches the structured records.
- [ ] All pages have been visually inspected after the final substantive edit.
- [ ] Tables fit within the printable width and repeat headers when split.
- [ ] Figures have alt text and remain legible at page width.
- [ ] Heading navigation, internal links, external links, and bookmarks work.
- [ ] Accessibility audit reports no unresolved high-, medium-, or low-severity findings.
- [ ] Personal author metadata and hidden sensitive content have been checked.
