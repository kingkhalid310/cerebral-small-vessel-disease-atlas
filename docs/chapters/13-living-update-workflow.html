Living Update Workflow

3 min readCore module0 linked sources
In this chapterUpdate cyclePriority queue

Update cycle

  1. Run and archive reproducible searches.
  2. Deduplicate by scholarly work, not local filename.
  3. Screen against explicit question-level criteria.
  4. Extract design, cohort lineage, reference standard, result, limitation, and status.
  5. Add supporting, qualifying, challenging, null, contextual, and methodological edges.
  6. Appraise bias and applicability independently when publication-grade use is intended.
  7. Reassess claims and hypotheses without automatically upgrading confidence.
  8. Regenerate the guide, website exports, validation reports, and changelog.
