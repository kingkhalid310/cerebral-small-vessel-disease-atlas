# Changelog

## v0.5.1 — Synchronized edition — 2026-08-18

### Added

- A one-command build that generates the website catalog, 15-chapter course, figures, and Word reading edition from maintained repository sources.
- A cryptographic synchronization manifest covering canonical inputs and published outputs.
- Four previously document-only chapters on diagnostic criteria, biomarkers, active debates, and the path to research fluency.
- A formal source-of-truth contract and a concrete roadmap for v0.6.

### Changed

- Expanded the course from 11 to 15 chapters and aligned the website, repository curriculum, and Word guide.
- Replaced release-specific language inside evergreen chapter content.

### Boundary

This patch synchronizes and deepens the existing curated corpus. It does not represent a new systematic search, clinical validation, or automated literature-surveillance system.

## v0.5 — Learning edition — 2026-08-18

### Added

- An 11-chapter web-native course generated from the maintained field guide.
- Persistent chapter navigation, in-page tables of contents, previous/next reading, and device-local completion marks.
- Eight guided entry pathways for beginners, CAA, arteriolosclerosis, criteria, differential reasoning, ARTS, MRI-autopsy design, and open-question discovery.
- A criteria and tools workbench comparing STRIVE-2, Boston criteria v2.0, and ARTS by purpose, output, reference logic, strongest use, and dangerous misuse.
- Evidence pages organized around conclusions, limitations, context, validation chains, and decisive next tests instead of raw CSV columns.

### Changed

- Rebuilt the visual system as a restrained editorial interface with smaller typography, denser information, and a reading-first hierarchy.
- Reframed the home page around learning and reasoning rather than repository statistics.
- Preserved the 202-record evidence library as the inspectable substrate beneath the course.

### Boundary

This is a product and presentation advance, not a new systematic search, meta-analysis, clinical validation, or autonomous literature-update system.

## v0.4 — Repository edition — 2026-08-18

### Added

- A self-contained GitHub repository with a clear public boundary.
- A dependency-free, responsive GitHub Pages website.
- Search and filters across questions, claims, studies, tools, hypotheses, cohorts, diagnostic profiles, and cases.
- Record-level pages generated from structured source data.
- Curated learning pathways for beginners, diagnostic-methods readers, and research designers.
- Standard-library scripts for catalog generation, validation, and local preview.
- Contribution, correction, source-suggestion, and research-question templates.
- Citation metadata, disclaimer, security guidance, domain activation instructions, and release governance.
- GitHub Actions validation for changes to structured evidence.

### Preserved from v0.3

- 61 scholarly sources and screening records.
- 21 structured pivotal studies.
- 24 claims with 67 evidence relationships.
- 40 research questions with 113 normalized evidence links.
- 19 tools, 12 hypotheses, 10 cohorts, 7 diagnostic profiles, and 8 cases.
- The 138-page reading edition and 14 original figures.

### Important boundary

This release reorganizes and exposes the evidence system; it does not claim a new systematic search, meta-analysis, consensus process, or clinical validation.
